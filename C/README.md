# 📁 Licence 2 - Programmation Impérative (C)

Ce dépôt regroupe l'ensemble des Travaux Pratiques (TP) et projets réalisés dans le cadre de l'unité d'enseignement de programmation impérative en C (Licence 2 Informatique).

## 🛠️ Environnement & Outils
* **Langage :** C (C99 ou supérieur)
* **Compilateur :** `gcc` (MSYS2)
* **Éditeur :** Visual Studio Code

## 📂 Structure du dépôt

Le dépôt est organisé par séances de TP (thématique)

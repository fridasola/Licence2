# Exercice 8 : 

Un triangle : - est équilatéral si tous ses côtés sont de même longueur,  - est isocèle s’il a deux côtés de même longueur, - est rectangle si les longueurs a, b, c de ses trois côtés vérifient a2 = b2 + c2 - est quelconque s’il ne vérifie aucune des propriétés précédentes. 
Ecrire un programme qui lit trois réels a, b et c représentant les longueurs des côtés d’un 
triangle et qui affiche la ou les propriété(s) du triangle

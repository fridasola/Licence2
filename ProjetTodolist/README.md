# 📝 Ma To-Do List en C (Projet L2)

Application de gestion de tâches en ligne de commande (CLI) développée dans le cadre de mon apprentissage de la programmation impérative en langage C (Licence 2 Informatique).

## 🚀 Fonctionnalités prévues / actuelles
- [x] Menu interactif en boucle
- [ ] Affichage de la liste des tâches
- [ ] Ajout d'une nouvelle tâche

## 🛠️ Outils & Compilation
* **Langage :** C (C99)
* **Compilateur :** `gcc`

### Comment compiler et lancer le projet :
1. Ouvrir un terminal dans le dossier du projet.
2. Compiler le fichier source :
   ``bash
   gcc todo.c``

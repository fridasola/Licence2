# Licence 2 - Programmation Impérative (C)

Ce dépôt regroupe l'ensemble des Travaux Pratiques (TP) réalisés dans le cadre de l'unité d'enseignement de programmation impérative en C (Licence 2 Informatique).

## Technologies & Outils
* **Langage :** C (C99 ou supérieur)
* **Compilateur :** `gcc` / `clang`
* **Outils de build :** `Makefile` (selon les dossiers)
* **Système :** Linux / Unix
